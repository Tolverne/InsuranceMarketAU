# InsuranceMarketAU

Open architecture and implementation workspace for an Australian motor insurance market data foundation and multi-participant simulation platform.

This repository will contain architecture documentation, data contracts, data-source metadata, reproducible population synthesis, insurer/brand/product model interfaces, simulation experiments and consulting analytics.

**Current stage:** M0 — architecture and data foundation specification. Design proposals are reviewed through pull requests.

**Data policy:** Do not commit raw vehicle-registration downloads, identifiable customer records, proprietary insurer quotes, model secrets or credentials. Record source metadata and licences in `docs/data-foundation/source-register.md` instead.

See the first architecture pull request for the detailed project structure and technical design.
