# M1.5 — Immutable population releases

**Status:** development in progress. Design goal: an independently verifiable, locally frozen, content-addressed population release, retaining M1.3b as a research baseline and M1.4b as an unapproved candidate. Every downstream enrichment or simulation must pin the release ID; replacing a population model creates a new release, never a silent overwrite. A published *research artifact* is not a validated commercial market population.
