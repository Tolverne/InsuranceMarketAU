# Source feasibility metadata

`bitre_2026_projections.json` records the **catalogue-observed dimensions** of 17 distinct BITRE cross-tabulations for 31 January 2026, plus a non-tabular explanatory notes resource. File-level resource URLs and checksum fields remain unset until the actual source files are retrieved and inspected.

Do **not** infer all possible combinations of variables from these projections; they are overlapping marginals of an unobserved national joint distribution, not rows for direct joining. See `docs/data-foundation/feasibility/bitre-2026-extract-inventory.md`.
