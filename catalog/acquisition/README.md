# Official source download catalogue

The `download-sources.json` file contains government source URLs, CKAN catalogue endpoints, declared types and reference-date folders. New releases can be added without editing downloader code.

Use `scripts/download_vehicle_sources.py`; see [the step-by-step download guide](../../docs/data-foundation/feasibility/downloading-data.md). Raw downloads, checksums and headers are recorded locally and **never committed** to the public Git repository.
